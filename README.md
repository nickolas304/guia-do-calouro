# Guia do Calouro

Um guia simples para ajudar quem está começando a estudar na escola. As informações são organizadas em seções para que possam ser atualizadas conforme a escola confirmar os detalhes.

## Índice

- [Horários](horarios.md)
- [Dicas de estudo](dicas-de-estudo.md)

## Equipe

- **Nickolas Sant’Ana** — organização e edição do guia (atividade individual).

## Privacidade

Este guia não publica dados pessoais. A seção de contatos deve conter somente canais institucionais confirmados pela escola. Informações que ainda precisam de confirmação estão identificadas como pendentes.
